# 钱多多上架准备

检查日期：2026-10-17。当前版本 2.0 (2)。这是一份准备清单，不表示 App Store 已验证通过或已提交。

## 已完成的本地准备

- 主 App 加入 PrivacyInfo.xcprivacy：不追踪，当前不向开发者收集数据；本机 UserDefaults 使用 CA92.1 原因。
- 评论提醒扩展加入独立隐私清单；其当前源码未直接访问需要声明原因的 API。
- 补充主 App 和扩展的 ITSAppUsesNonExemptEncryption=false。当前代码依赖 Apple 系统 CloudKit / 系统安全能力，没有自建加密实现或第三方加密库；未来加入这类功能时须重新判断。
- 设置加入离线隐私政策和动态版本入口。现有“汇总”右上角已有齿轮入口，不需要隐藏手势。
- 图标完整，源文件移除全不透明的 alpha 通道，逐像素确认 RGB 与原图相同。
- 默认庆祝音效为已获 CC0 授权的多人 Yay，附许可及哈希；原私人录音不在当前资源中。
- 商店中文描述、关键词和审核备注草稿见[商店资料](商店资料.zh-Hans.md)。维护者已确认使用当前项目 GitHub Issues 作为联系渠道，设置中也提供帮助与反馈入口。
- 本地导出参数见 ExportOptions.plist，仅设置本地导出，没有上传动作。

本轮未替你注册账号、接受协议、改动 CloudKit 生产 schema、创建分发证书、上传构建或提交审核。

## 仍须在开发者账号确认

1. 维护者已确认 Apple Developer 账号开通且 App Store Connect 可登录；当前浏览器登录页加载异常，尚未进入账号，因此未核实 App 记录或构建历史。待签协议需账号持有人按实际情况处理。只有需要收费等业务时，再按账号要求补齐相应银行及税务资料。
2. App Store Connect 有与原工程 Bundle ID 对应的 App 记录；名称“钱多多”的可用性需由商店验证。保持原工程的 Bundle ID 与 iCloud 容器，公开 GitHub 工程中的 com.example 只供他人构建，不能拿来更新你原来的 App。
3. 分发签名：本机只检查到 Apple Development 身份和开发配置，未发现 Apple Distribution 身份或对应 App Store 分发 profile。可在已登录正确团队的 Xcode 中使用自动签名准备正式分发。不要把开发签名包或本轮未签名归档直接当作可上传 IPA。
4. 构建号 2 是否已使用过；若已上传，主 App 和扩展需使用一致的新构建号。未读取账号历史前，本轮没有擅自改成“保证可用”的号码。
5. CloudKit Console 检查当前容器的 Production schema，核对 AdRecord、FollowerSnapshot、VideoLikeSnapshot、SyncSpace 及评论提醒字段与索引。开发环境可用不代表生产已部署；部署 schema 只复制结构，不迁移开发记录。审核后确认，再按[Apple 官方步骤](https://developer.apple.com/documentation/cloudkit/deploying-an-icloud-container-s-schema)部署。
6. 正式导出包中的 CloudKit/APNs entitlements 应与分发 profile 对应 Production。不要直接把共享源文件中的 development 改成 production 来“修复”，否则会影响日常开发测试。

## 隐私和商店申报

- PrivacyInfo.xcprivacy 与 App Store Connect 隐私问卷是两件事，加入清单不会自动完成商店申报。
- 当前代码不含开发者后端、广告或统计 SDK。业务记录保存在本机及用户的 iCloud 私有/共享空间，开发者不通过该实现访问其他用户私有内容；庆祝录音、偏好和日志只留本机。因此当前实现支持申报“不收集数据”，前提是实际运营没有另外收集客服日志、备份或使用统计等内容。账号持有人应按实际使用确认；不能把它表述为“所有信息永远不离开设备”。
- 用户主动通过 GitHub 提交反馈时，所提交内容可能公开。正式反馈运营方式如有改变，应重新判断 Customer Support 等数据及 Apple 的可选披露条件。
- 隐私政策使用公开源码的文件页：https://github.com/wangchenlin0501/qianduoduo/blob/main/%E9%92%B1%E5%A4%9A%E5%A4%9A/PrivacyPolicy.txt 。正文为 `钱多多/PrivacyPolicy.txt`；线上公开可读后，将该真实 URL 保存到 App Store Connect 的 Privacy Policy URL。当前没有自动填写账号端问卷或链接字段。
- 填写真实支持入口、审核联系人、电话、版权名称、价格及上架地区，不要用猜测的身份信息。
- 按新版年龄分级问卷如实填写，不预先保证某个等级。当前 app 没有自建账号注册，无须仅因使用 iCloud 就添加独立账号删除流程；仍应向用户说明记录、共享、iCloud 数据和备份的管理方式。
- 选择欧盟销售地区时需确认 DSA trader 身份及联系信息，不能仅凭“免费”自动判定非商家。[Apple 官方说明](https://developer.apple.com/help/app-store-connect/manage-compliance-information/manage-european-union-digital-services-act-trader-requirements/)
- 如面向中国大陆，请按 App Store Connect 的要求核实 ICP 备案及适用信息，不能假定全球勾选后所有地区都可上架。[Apple 上架状态说明](https://developer.apple.com/cn/help/app-store-connect/reference/app-information/app-and-submission-statuses)

## 归档与本地复查

从原工程打开 Xcode，选择“钱多多”Scheme、通用 iOS 设备、Release Archive。完成分发签名后在 Organizer 使用 Validate App，再考虑上传并先用 TestFlight 验证。

源码资源检查：

```sh
python3 scripts/verify-app-store.py
```

保存归档后检查其资源（路径替换为实际归档）：

```sh
python3 scripts/verify-app-store.py --archive /path/to/QianDuoDuo.xcarchive
```

已有正确签名的归档后，可按本地导出参数准备包；此命令不会自行上传：

```sh
xcodebuild -exportArchive -archivePath /path/to/QianDuoDuo.xcarchive \
  -exportPath /path/to/export -exportOptionsPlist AppStore/ExportOptions.plist
```

通过编译、资源检查或带开发签名，都不代表已通过 Apple 分发验证、审核或生产环境验收。
